## 直接安装

已生成的安装包位于：`E:\123pan\BiliLite-main\交付\BiliLite-personal-debug.apk`。

你可以跳过下面的“自行重新打包”，直接把这个 APK 传到手机并通过卓易通安装。

## 自行重新打包（以后修改源码时使用）

1. 用 Android Studio 打开 `E:\123pan\BiliLite-main\android`，不是外层文件夹。
2. 按项目配置准备 JDK 17、Android SDK Platform 35 和 Build Tools 35.0.0。让 Android Studio 完成 Gradle 同步；所需依赖由你的电脑下载。
3. 在 Android Studio 终端执行下面两行，生成 debug APK。

```powershell
Set-Location 'E:\123pan\BiliLite-main\android'
.\gradlew.bat assembleDebug
```

输出位置：`E:\123pan\BiliLite-main\android\app\build\outputs\apk\debug\app-debug.apk`。

没有 Android Studio，或出现 SDK、Java、Gradle、下载依赖、编译方面的报错时，请停在该步骤，把提示截图或完整错误文字发来。不需要自行卸载软件或猜测该修改哪个设置。

## 保留原版安装

- 将生成的 APK 传到手机，通过卓易通安装。
- debug 包名为 `com.bililite.app.personal`，桌面名称为“BiliLite 改进版”，与原版分开存储数据，不需要先卸载原版。
- 改进版需要重新登录。原版“我的 → 数据同步与日志 → 导出全部数据”可以备份现有内容，再在改进版手动导入。原版不要删除。
- 源项目旧 BUILD.md 中“安装前卸载旧版”的建议不适用于这个独立 debug 包。

## 这次的操作行为

- 后台播放默认开启，开关位于播放页的信息区。若导入的备份或插件曾关闭该设置，请手动打开。
- 切换应用或锁屏时继续音频与播放进度；锁屏时不强行显示视频或点亮屏幕。
- 点播放器控制条的“系统画中画”图标进入小窗；不会在每次切换应用时自动弹窗。
- 画中画中隐藏应用的导航、详情与普通控制条，系统媒体会话提供播放控制。
- 返回按钮退出播放页，或从最近任务中明确移除应用，会停止播放。
- 首页的视频列表、网格和 BV 搜索结果增加日期；没有有效日期时显示“发布日期未知”，不会用收藏时间或当前日期代替。
- “我的 → 管理UP主”新增“从我的关注批量添加”：读取当前登录账号的正在关注列表，按关注时间排序，支持搜索、分页加载、多选和批量添加。
- 关注列表改为固定分页：每页 50 条，显示总数、上一页、下一页、页码跳转；切页直接替换当前页，不合并多页，也不会把新页条目插入旧页。
- 批量添加沿用原有同步逻辑，按顺序逐个添加 UP 并同步其视频；原来的手动搜索入口继续保留。

## 逐项反馈

1. 正常播放到中段，切到其他应用约一分钟再返回。记录是否仍有声音、进度是否正常推进、是否回到首页。
2. 开启后台播放，锁屏约两分钟后解锁；再试一次较长时间的锁屏。记录何时停止，以及锁屏或通知区域是否有可用的播放控制。
3. 播放中点击应用新加的画中画按钮，然后展开、再次缩小。记录是否重载、黑屏、声音中断或回到首页。
4. 另试你原先使用的系统缩窗手势或入口。请分别记录它与应用内画中画按钮的结果，二者在卓易通中可能走不同路径。
5. 暂停后进入、退出小窗，确认不会自行开始播放；尝试关闭后台播放后切换应用，确认会暂停。
6. 尝试切换分P、清晰度和自动下一集，确认不会跳到上一段的位置。再试通知控制、耳机断开、其他音频抢占后的表现。
7. 查看首页发布日期，选两个视频对照 B 站原始发布日期。如果旧视频显示未知，可在“管理UP主”重新同步对应 UP；不要删除原有数据。
8. 返回退出视频，确认声音和播放通知消失；重新打开同一视频，确认历史记录没有被归零。

反馈时带上：操作步骤、出错前后截图、后台播放开关状态、是否使用新加的画中画按钮，以及卓易通版本。必要时再从“我的 → 数据同步与日志”导出日志。日志或截图如含账号、Cookie、令牌等敏感信息，请先遮盖。

## 兼容性边界

本次按 Android 标准媒体播放服务和画中画接口实现。卓易通是否向 APK 提供画中画、媒体通知和持续后台运行能力，需要你的 Pura 70 Pro+ / 鸿蒙 6 实测。若宿主强行结束整个应用进程，不能仅靠保留页面状态保证不中断。

实现依据：[Android 后台媒体播放](https://developer.android.com/media/media3/session/background-playback)、[Android 系统画中画](https://developer.android.com/develop/ui/views/picture-in-picture)。这些是 Android 接口文档，不是卓易通兼容性认证。
